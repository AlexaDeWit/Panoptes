# Repository moves this project has accepted, one per line:
#
#   name old-repository new-repository
#
# scripts/check-provenance.mjs verifies each catalog package's npm provenance
# attestation and reads the source repository out of it, then compares that
# against the same package on the base commit. A package whose attestation
# now names another repository fails the check unless the move is written
# here exactly, both repositories named, so accepting one move leaves the
# next one a decision. A "-" stands for an attestation whose provenance
# statement names no repository.
#
# Nothing else is committed. What carries an attestation, and what publishes
# none at all, is computed and printed on every run.
