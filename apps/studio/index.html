Threat modelling in the diagram

Saerskriven is an open-source threat modelling studio. Draw a system as a data-flow diagram, then record each threat on the element it affects.

Open and save Threat Dragon v2 JSON or Saerskriven YAML in your browser. The command-line interface also validates models and renders SVG, Markdown, and PDF.
