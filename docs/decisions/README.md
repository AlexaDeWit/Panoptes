# Decision records

Why the project is shaped the way it is, when no better home for the why
exists. The admission policy lives in
[CONTRIBUTING.md](../../CONTRIBUTING.md#decision-records).

Format: one file, `NNNN-short-slug.md`, with four sections: Status, Context,
Decision, Consequences. Keep it under a screen. Supersede by adding a new
record and marking the old one superseded, never by rewriting history.
