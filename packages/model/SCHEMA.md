# Internal model schema

The whole internal model, expanded from the zod schemas that define it.
`parseModel` is the only way a model value comes into existence, and it
enforces more than the shapes below: element, diagram, threat, mitigation
and assumption ids unique where they must be, threat numbers unique and
never above `lastIssuedThreatNumber`, flow endpoints anchored inside their
own diagram and never to the flow itself, and every element and threat
reference resolving.

A field of type `text` accepts every letter, mark, number, punctuation,
symbol and space separator Unicode defines, plus tab, line feed and
carriage return, plus the format characters a script owns: every one
Unicode gives a script of its own, the Arabic number signs and letter
mark, the Syriac abbreviation mark, the Mongolian vowel separator and
the Kaithi and Egyptian hieroglyph format controls among them, together
with the zero width non-joiner U+200C, the zero width joiner U+200D and
the Arabic marks U+0605, U+06DD and U+08E2 that Unicode files as
belonging to no script.

It refuses the rest: every other control character, the format
characters no script owns, among them the soft hyphen U+00AD, the
bidirectional controls U+200E, U+200F, U+202A to U+202E and U+2066 to
U+2069, the zero width space U+200B, the word joiner and the invisible
operators U+2060 to U+206F, the byte order mark U+FEFF and the tag
characters, so a subdivision flag built from tags is refused where every
other emoji sequence is not, the line and paragraph separators U+2028 and
U+2029, private use, unassigned code points, and an unpaired surrogate.
The empty string is text, and a field carrying a length says so beside
its type.

Generated by `src/lib/schema-report.ts` and checked against the schemas on
every test run, so it cannot fall behind them. Regenerate it with
`pnpm nx test @panoptes/model -- -u`.

- `metadata`: object
  - `title`: text
  - `owner`: text
  - `description`: text
  - `contributors`: list of text
- `diagrams`: list of object
  - `id`: DiagramId (text, at least 1 character)
  - `title`: text
  - `elements`: list of one of 6, told apart by `kind`
    - when `kind` is `actor`
      - `id`: ElementId (text, at least 2 characters)
      - `name`: text
      - `description`: text
      - `outOfScope`: boolean
      - `reasonOutOfScope`: text
      - `position`: object
        - `x`: number
        - `y`: number
      - `size`: object
        - `width`: number, greater than 0
        - `height`: number, greater than 0
    - when `kind` is `process`
      - `id`: ElementId (text, at least 2 characters)
      - `name`: text
      - `description`: text
      - `outOfScope`: boolean
      - `reasonOutOfScope`: text
      - `position`: object
        - `x`: number
        - `y`: number
      - `size`: object
        - `width`: number, greater than 0
        - `height`: number, greater than 0
    - when `kind` is `store`
      - `id`: ElementId (text, at least 2 characters)
      - `name`: text
      - `description`: text
      - `outOfScope`: boolean
      - `reasonOutOfScope`: text
      - `position`: object
        - `x`: number
        - `y`: number
      - `size`: object
        - `width`: number, greater than 0
        - `height`: number, greater than 0
    - when `kind` is `flow`
      - `id`: ElementId (text, at least 2 characters)
      - `name`: text
      - `description`: text
      - `outOfScope`: boolean
      - `reasonOutOfScope`: text
      - `source`: one of 2, told apart by `kind`
        - when `kind` is `attached`
          - `element`: ElementId (text, at least 2 characters)
        - when `kind` is `free`
          - `position`: object
            - `x`: number
            - `y`: number
      - `target`: one of 2, told apart by `kind`
        - when `kind` is `attached`
          - `element`: ElementId (text, at least 2 characters)
        - when `kind` is `free`
          - `position`: object
            - `x`: number
            - `y`: number
      - `waypoints`: list of object
        - `x`: number
        - `y`: number
    - when `kind` is `trust-boundary`
      - `id`: ElementId (text, at least 2 characters)
      - `name`: text
      - `description`: text
      - `outOfScope`: boolean
      - `reasonOutOfScope`: text
      - `shape`: one of 2, told apart by `kind`
        - when `kind` is `box`
          - `position`: object
            - `x`: number
            - `y`: number
          - `size`: object
            - `width`: number, greater than 0
            - `height`: number, greater than 0
        - when `kind` is `curve`
          - `waypoints`: list of at least 2 object
            - `x`: number
            - `y`: number
    - when `kind` is `text`
      - `id`: ElementId (text, at least 2 characters)
      - `name`: text
      - `description`: text
      - `outOfScope`: boolean
      - `reasonOutOfScope`: text
      - `position`: object
        - `x`: number
        - `y`: number
      - `size`: object
        - `width`: number, greater than 0
        - `height`: number, greater than 0
      - `text`: text
- `threats`: list of object
  - `id`: ThreatId (text, at least 2 characters)
  - `number`: integer, greater than 0
  - `title`: text
  - `category`: one of 6, told apart by `methodology`
    - when `methodology` is `STRIDE`
      - `category`: one of `spoofing`, `tampering`, `repudiation`, `information-disclosure`, `denial-of-service`, `elevation-of-privilege`
    - when `methodology` is `LINDDUN`
      - `category`: one of `linking`, `identifying`, `non-repudiation`, `detecting`, `data-disclosure`, `unawareness`, `non-compliance`
    - when `methodology` is `CIA`
      - `category`: one of `confidentiality`, `integrity`, `availability`
    - when `methodology` is `CIA-DIE`
      - `category`: one of `confidentiality`, `integrity`, `availability`, `distributed`, `immutable`, `ephemeral`
    - when `methodology` is `PLOT4ai`
      - `category`: one of `accountability-and-human-oversight`, `bias-fairness-and-discrimination`, `cybersecurity`, `data-and-data-governance`, `ethics-and-human-rights`, `privacy-and-data-protection`, `safety-and-environmental-impact`, `transparency-and-accessibility`
    - when `methodology` is `custom`
      - `methodologyName`: text, at least 1 character
      - `category`: text, at least 1 character
  - `severity`: one of `low`, `medium`, `high`, `critical`, `undecided`
  - `status`: one of `open`, `mitigated`, `transferred`, `avoided`, `accepted-risk`, `eliminated`, `not-applicable`
  - `description`: text
  - `mitigation`: text
  - `elements`: list of ElementId (text, at least 2 characters)
- `lastIssuedThreatNumber`: integer, 0 or more
- `mitigations`: list of object
  - `id`: MitigationId (text, at least 2 characters)
  - `title`: text
  - `prose`: text
  - `status`: one of `proposed`, `implemented`, `verified`
  - `threats`: list of ThreatId (text, at least 2 characters)
- `assumptions`: list of object
  - `id`: AssumptionId (text, at least 2 characters)
  - `prose`: text
  - `status`: one of `valid`, `invalidated`
  - `elements`: list of ElementId (text, at least 2 characters)
  - `threats`: list of ThreatId (text, at least 2 characters)
