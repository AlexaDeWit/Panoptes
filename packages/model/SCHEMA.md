# Internal model schema

The whole internal model, expanded from the zod schemas that define it.
`parseModel` is the only way a model value comes into existence, and it
enforces more than the shapes below: element, diagram, threat, mitigation
and assumption ids unique where they must be, threat numbers unique and
never above `lastIssuedThreatNumber`, flow endpoints anchored inside their
own diagram and never to the flow itself, and every element and threat
reference resolving.

Generated by `src/lib/schema-report.ts` and checked against the schemas on
every test run, so it cannot fall behind them. Regenerate it with
`pnpm nx test @panoptes/model -- -u`.

- `metadata`: object
  - `title`: string
  - `owner`: string
  - `description`: string
  - `contributors`: list of string
- `diagrams`: list of object
  - `id`: DiagramId (string, at least 1 character)
  - `title`: string
  - `elements`: list of one of 6, told apart by `kind`
    - when `kind` is `actor`
      - `id`: ElementId (string, at least 1 character)
      - `name`: string
      - `description`: string
      - `outOfScope`: boolean
      - `reasonOutOfScope`: string
      - `position`: object
        - `x`: number
        - `y`: number
      - `size`: object
        - `width`: number, greater than 0
        - `height`: number, greater than 0
    - when `kind` is `process`
      - `id`: ElementId (string, at least 1 character)
      - `name`: string
      - `description`: string
      - `outOfScope`: boolean
      - `reasonOutOfScope`: string
      - `position`: object
        - `x`: number
        - `y`: number
      - `size`: object
        - `width`: number, greater than 0
        - `height`: number, greater than 0
    - when `kind` is `store`
      - `id`: ElementId (string, at least 1 character)
      - `name`: string
      - `description`: string
      - `outOfScope`: boolean
      - `reasonOutOfScope`: string
      - `position`: object
        - `x`: number
        - `y`: number
      - `size`: object
        - `width`: number, greater than 0
        - `height`: number, greater than 0
    - when `kind` is `flow`
      - `id`: ElementId (string, at least 1 character)
      - `name`: string
      - `description`: string
      - `outOfScope`: boolean
      - `reasonOutOfScope`: string
      - `source`: one of 2, told apart by `kind`
        - when `kind` is `attached`
          - `element`: ElementId (string, at least 1 character)
        - when `kind` is `free`
          - `position`: object
            - `x`: number
            - `y`: number
      - `target`: one of 2, told apart by `kind`
        - when `kind` is `attached`
          - `element`: ElementId (string, at least 1 character)
        - when `kind` is `free`
          - `position`: object
            - `x`: number
            - `y`: number
      - `waypoints`: list of object
        - `x`: number
        - `y`: number
    - when `kind` is `trust-boundary`
      - `id`: ElementId (string, at least 1 character)
      - `name`: string
      - `description`: string
      - `outOfScope`: boolean
      - `reasonOutOfScope`: string
      - `shape`: one of 2, told apart by `kind`
        - when `kind` is `box`
          - `position`: object
            - `x`: number
            - `y`: number
          - `size`: object
            - `width`: number, greater than 0
            - `height`: number, greater than 0
        - when `kind` is `curve`
          - `waypoints`: list of at least 2 object
            - `x`: number
            - `y`: number
    - when `kind` is `text`
      - `id`: ElementId (string, at least 1 character)
      - `name`: string
      - `description`: string
      - `outOfScope`: boolean
      - `reasonOutOfScope`: string
      - `position`: object
        - `x`: number
        - `y`: number
      - `size`: object
        - `width`: number, greater than 0
        - `height`: number, greater than 0
      - `text`: string
- `threats`: list of object
  - `id`: ThreatId (string, at least 1 character)
  - `number`: integer, greater than 0
  - `title`: string
  - `category`: one of 6, told apart by `methodology`
    - when `methodology` is `STRIDE`
      - `category`: one of `spoofing`, `tampering`, `repudiation`, `information-disclosure`, `denial-of-service`, `elevation-of-privilege`
    - when `methodology` is `LINDDUN`
      - `category`: one of `linking`, `identifying`, `non-repudiation`, `detecting`, `data-disclosure`, `unawareness`, `non-compliance`
    - when `methodology` is `CIA`
      - `category`: one of `confidentiality`, `integrity`, `availability`
    - when `methodology` is `CIA-DIE`
      - `category`: one of `confidentiality`, `integrity`, `availability`, `distributed`, `immutable`, `ephemeral`
    - when `methodology` is `PLOT4ai`
      - `category`: one of `accountability-and-human-oversight`, `bias-fairness-and-discrimination`, `cybersecurity`, `data-and-data-governance`, `ethics-and-human-rights`, `privacy-and-data-protection`, `safety-and-environmental-impact`, `transparency-and-accessibility`
    - when `methodology` is `custom`
      - `methodologyName`: string, at least 1 character
      - `category`: string, at least 1 character
  - `severity`: one of `low`, `medium`, `high`, `critical`, `undecided`
  - `status`: one of `open`, `mitigated`, `transferred`, `avoided`, `accepted-risk`, `eliminated`, `not-applicable`
  - `description`: string
  - `mitigation`: string
  - `elements`: list of ElementId (string, at least 1 character)
- `lastIssuedThreatNumber`: integer, 0 or more
- `mitigations`: list of object
  - `id`: MitigationId (string, at least 1 character)
  - `title`: string
  - `prose`: string
  - `status`: one of `proposed`, `implemented`, `verified`
  - `threats`: list of ThreatId (string, at least 1 character)
- `assumptions`: list of object
  - `id`: AssumptionId (string, at least 1 character)
  - `prose`: string
  - `status`: one of `valid`, `invalidated`
  - `elements`: list of ElementId (string, at least 1 character)
  - `threats`: list of ThreatId (string, at least 1 character)
